# 开场视频放置指南

开始页与模式选择界面的视频从 `frontend/public/placeholder-videos/` 目录加载。
制作好视频后放入对应文件，刷新页面即可生效（无需改代码）。

## 文件结构

```
frontend/public/placeholder-videos/
├── splash_main.mp4    开屏主视频（待点击态循环播放，占比 80%）
├── splash_extra_1.mp4 开屏穿插视频 1（随机穿插，占比 10%）
├── splash_extra_2.mp4 开屏穿插视频 2（随机穿插，占比 10%）
├── intro.mp4          进入动画（点击后播放一次，播完进入模式选择）
└── menu_bg.mp4        模式选择界面动态背景（循环播放）
```

## 播放策略说明

- **开屏待点击态**：`splash_main.mp4` 为主播放视频，占约 80%；`splash_extra_1.mp4` 与
  `splash_extra_2.mp4` 在循环过程中随机穿插，各占约 10%。每次主视频播完按概率决定下一段
  （80% 继续主视频 / 10% 穿插 1 / 10% 穿插 2），穿插视频播完自动回到主视频。
- **进入动画**：点击后播放 `intro.mp4` 一次，播完自动进入模式选择界面（可点击跳过）。
- **模式选择界面**：`menu_bg.mp4` 作为动态背景循环播放。

## 说明

- **视频缺失时**：
  - 开屏主视频缺失 → 自动回退粒子动画背景 + 标题，点击后 3 秒进入模式选择，游戏不受影响
  - 开屏穿插视频缺失 → 跳过该段，自动回到主视频
  - 进入动画缺失 → 点击后 3 秒进入模式选择
  - 模式选择背景缺失 → 自动回退紫色光晕背景
- 建议 MP4 格式（H.264 编码，浏览器兼容性最好）
- 视频默认 `muted`（静音）播放，避免浏览器自动播放限制
- 开屏主视频与穿插视频建议循环友好（首尾衔接），时长尽量一致以贴近 80/10/10 比例
