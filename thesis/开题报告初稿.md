## 一、选题背景与研究意义

### 1.1 游戏 AI 的范式演进

游戏长期以来是人工智能研究的核心试验场。从深蓝击败国际象棋世界冠军，到 AlphaGo 基于深度神经网络与蒙特卡洛树搜索战胜人类围棋职业棋手[1]，再到 AlphaZero 在围棋、国际象棋、将棋三个领域通过自我对弈实现通用突破[2]，经典范式可以概括为"规则与搜索 + 深度强化学习"。这一范式的代表成果还包括 AlphaStar 在《星际争霸 II》达到宗师级水平[3]、OpenAI Five 在 Dota 2 战胜职业战队[4]，以及在德扑等不完全信息博弈中实现超人类表现的 Pluribus[5]。然而，该范式的成本极高：依赖大规模自博弈、海量算力与精心设计的奖励函数，普通开发者与中小团队难以复现。

大语言模型（LLM）的兴起为游戏 AI 提供了第三条路径。思维链（Chain-of-Thought）提示使模型显式地进行多步推理[6]，ReAct 框架将推理与行动交替融合[7]；Voyager 在《我的世界》中通过技能库实现终身学习[8]，生成式智能体（Generative Agents）在虚拟小镇中涌现出可信的社会行为[9]，CICERO 更是在需要自然语言谈判的《外交》（Diplomacy）中达到人类水平[10]。这些工作表明：LLM 具备常识、推理与指令遵循能力，能够以极低的边际成本充当游戏决策主体，但其在**对抗性、信息不对称、动作空间形式化可验证**的策略博弈场景中的能力边界，尚未得到系统的检验。

### 1.2 信息不对称推理博弈：理想的试验场

开放世界游戏（如《我的世界》）的失败标准模糊、动作空间开放，难以客观量化智能体能力；棋类游戏状态完全可观测，无法覆盖真实决策中的信息博弈。信息不对称推理博弈处于两者之间：**状态部分可观测、推理链条可形式化、胜负信号明确**，是检验 LLM 推理能力与工程化可行性的理想中间地带。

《幸福的丝线》是一款 5×5 棋盘、双阵营信息不对称的回合制推理对战游戏（独立开发，已开源并在云服务器上线）。其规则设计具有三个对 AI 研究极具价值的特性：

1. **信息不对称**：正派玩家不知道 3 名反派的具体身份，只能通过监视反馈与死亡标记的空间约束进行贝叶斯推理；反派全知，通过行动制造信息迷雾。
2. **形式化可验证**：每一步行动都受严格硬约束——死亡标记必须落在行动者影响范围内（十字或九宫格）、满员行动人数 k=min(c,a)、禁止标记同伙、监视者与死亡者不能行动。不存在模糊裁决空间。
3. **决策链条完整**：6 回合、每回合 3 阶段，正派的信息获取（监视）与反派的信息隐藏（行动卡调度）构成完整的攻防闭环。

上述特性使该游戏成为验证 LLM 智能体"推理—决策—对抗"能力的天然试验场：动作合法性可自动校验（消除幻觉影响）、策略优劣可由胜率客观度量（可自动评测）、领域知识可由规则约束显式表达（可结构化蒸馏）。

### 1.3 研究意义

**理论意义**：本研究系统考察 LLM 在对抗性不完全信息博弈中的推理能力边界，探究"领域知识蒸馏式提示策略"与"参数化微调"两条知识注入路径的互补关系，为 LLM 智能体的结构化决策研究提供可复现的案例与基准。

**工程意义**：本研究提出一条**自举式（bootstrap）训练数据生成与迭代优化**管线，以规则 AI 自对弈与 LLM 对局录制替代昂贵的人工数据采集；并验证本地 QLoRA 微调在消费级显卡（8GB 显存）上的可行性与实时性，为中小团队低成本构建游戏 AI 提供可迁移方案。

**应用意义**：研究成果可直接应用于游戏 NPC 智能化、推理类游戏陪练、桌面游戏数字人等场景；所构建的评测基准（分级难度对手 + 动作合法率/胜率双指标体系）可作为后续同类研究的对照基线。

## 二、国内外研究现状

### 2.1 经典游戏 AI 与不完全信息博弈

在完全信息博弈方向，AlphaGo[1]、AlphaZero[2] 确立了"深度网络 + 自博弈强化学习"的范式；在实时策略方向，AlphaStar[3] 与 OpenAI Five[4] 展示了多智能体强化学习的规模极限。在不完全信息博弈方向，Pluribus 证明了搜索与博弈论方法可在六人德扑中战胜人类专家[5]；Hanabi 挑战赛则定义了合作型不完全信息推理的基准[11]。这些工作的共同特征是**大规模算力依赖与低数据效率**——其方法难以迁移到资源受限的普通开发场景。

### 2.2 LLM 的推理能力与智能体框架

Wei 等人发现思维链提示可显著提升大模型在多步推理任务上的表现[6]；Kojima 等人进一步证明无需示例的零样本思维链同样有效[12]；Yao 等人提出 ReAct 框架，使推理与行动在统一循环中交替进行[7]。在游戏与虚拟环境中，Voyager 在《我的世界》中构建可复用的技能库实现自主探索[8]；Generative Agents 赋予智能体记忆、反思与规划机制[9]；Meta 的 CICERO 将策略网络与语言模型结合，在需要谈判与欺骗的《外交》游戏中达到人类水平[10]，是 LLM 应用于对抗性不完全信息博弈的代表性工作。

### 2.3 LLM 对齐与参数高效微调

OpenAI 的 InstructGPT 确立了"监督微调（SFT）+ 人类反馈强化学习（RLHF）"的指令对齐范式[13]；Rafailov 等人提出的 DPO 以直接偏好优化替代显式奖励模型，显著降低了偏好对齐的训练门槛[14]。在参数高效微调方面，LoRA 以低秩适配实现轻量微调[15]，QLoRA 通过 4bit 量化进一步将微调显存需求降低到消费级硬件可承受的范围[16]；LLaMA-Factory 等框架统一封装了百余种模型的高效微调流程[17]；以 Qwen2.5 为代表的开源模型系列为本地微调提供了高质量基座[18]。

### 2.4 研究现状述评与本文切入点

综合以上工作可以发现三个研究缺口：

1. **场景缺口**：LLM 游戏智能体的研究集中于开放世界与文本环境，在"规则形式化、动作可校验、胜负客观"的对抗性推理博弈中的系统研究不足。CICERO 虽属此类，但其系统规模庞大、难以复现，缺乏一个**中小规模、低成本、可完整验证**的试验平台。
2. **知识注入路径缺口**：领域知识通过提示词注入与通过微调注入两种方式的**效果差异与互补关系**，在博弈决策场景中缺乏对照实验。
3. **数据获取缺口**：博弈决策的高质量训练数据依赖对局与标注，获取成本高。如何利用已有规则 AI 与 LLM 自身构建**自举式数据管线**，是低成本落地 LLM 游戏智能体的关键工程问题。

本文以《幸福的丝线》为试验场，针对上述三个缺口展开研究。

## 三、研究内容与研究目标

### 3.1 研究内容一：基于领域知识蒸馏的提示策略体系（主体已完成）

将大师级玩家的解题框架显式化、结构化为可注入 LLM 的提示策略，是本研究的核心内容之一，具体包括：

- **原则体系**：正派推理八原则（P1~P8）与反派策略六原则（R1~R6），覆盖信息获取、嫌疑排除、行动卡调度、误导布局等完整决策环节，实现领域专家知识的显式化与结构化表示；
- **四段式思维链模板**："看到（观测）→ 推断（更新信念）→ 比较（候选动作评估）→ 决定（输出动作）"，强制模型按可审计的推理链路输出；
- **回合策略协议**：针对 6 回合结构的分阶段策略（第 2~4 回合积累信念、第 5 回合放钓位换取反馈、第 6 回合锁定目标）；
- **信念表示与启发式决策策略**：以贝叶斯推理的概率信念表示（信念热度图）作为提示输入的一部分，并引入"信念优先"与"范围内命中计数"等基于不完全信息的启发式决策策略打破平局。

该体系经过 3 轮消融式提示策略迭代（信念优先原则 → 回合策略协议 → 命中计数判别法），已达成阶段性成果（见 3.4）。

### 3.2 研究内容二：自举式训练数据生成与迭代优化（管线已完成，微调为计划）

- **对局录制器**：在单人模式中采集决策点样本，每一条样本为"局面 → 推理链 → 动作"三元组，支持规则 AI 对局与 LLM 对局（含思维链）两种采集方式；
- **质量分档机制**：按推理充实度与行动命中数将样本自动分为 A/B/C 三档，C 档作为 DPO 负例来源；
- **人机协同标注框架**：制定标注指南（四段式思维链标准、原则枚举、一票否决、A/B/C 评级），采用"AI 标注员草稿 + 人类审校"的双标注流程，并开发录制数据自动审计器（回放式五层校验）；
- **监督微调与偏好对齐（计划）**：在已构建的 SFT 数据集（350 条，ShareGPT 格式）与 DPO 负例集（148 条）基础上，**计划**对比评估两条微调路线——路线一为云端 API 微调（如 DeepSeek 开放平台，零硬件门槛但推理成本线性增长）；路线二为本地 QLoRA 微调（以 Qwen2.5 为基座、LLaMA-Factory 为工具，训练产物为 adapter 权重，可本地部署实现零边际推理成本）。基于开发者硬件（RTX 4060 Laptop 8GB 显存）的选型决策为：3B 模型起步建立基线，效果不足时升级 7B（需梯度检查点与小 batch）；DPO 因当前负例规模不足（通常需 1k~10k 成对数据）列为后期计划。

### 3.3 研究内容三：评测基准构建与多策略后端解耦架构

- **两级评测体系**：L1 基础能力层（动作合法率、格式正确率、回退率）+ L2 策略能力层（对局胜率、监视命中率，按 easy/normal/hard 三档难度对手分别统计）；
- **对照组设计**：以双阵营规则 AI（正派：贝叶斯推断 + 几何硬约束 + 组合级指派；反派：信息泄漏最小化评分）为对照基线，其难度梯度实测为 easy 89% / normal 62% / hard 48%；
- **消融实验设计（计划）**：纯提示策略 vs 提示策略+SFT vs 提示策略+SFT+DPO 三组对照，用于分离提示策略与参数化微调的贡献；
- **多策略决策后端解耦架构**：以 Brain 抽象层实现规则 AI 与 LLM 智能体的双后端插拔，保证评测的公平性与工程的可替换性。

### 3.4 研究目标

| 目标 | 指标 | 状态 |
|---|---|---|
| 目标一 | LLM 智能体动作合法率 100%、格式正确率 100%、回退率 0% | 已达成 |
| 目标二 | 提示策略下，vs easy 档胜率 ≥80%、vs normal ≥55%、vs hard ≥40% | 已达成（实测 80% / 58% / 40%） |
| 目标三 | SFT 微调后各难度档胜率不低于提示词基线，DPO 后进一步逼近规则 AI 基线 | 计划（待训练验证） |
| 目标四 | 产出可复用的评测基准、SFT/DPO 数据集与本地部署方案 | 部分达成（数据集 350/148 条，计划扩充） |

## 四、关键技术路线

本研究的技术路线分为四个层次：**观测编码 → 决策推理 → 反馈优化 → 评测回归**，形成闭环。

### 4.1 总体架构

```
游戏对局引擎（状态机 / 硬约束校验）
        │
        ▼
Brain 抽象层（多策略决策后端解耦：规则 AI ⇋ LLM 智能体）
        │
        ▼
StateEncoder 观测编码层
  ├─ 信息边界过滤（按阵营过滤不可见信息，模拟真实玩家视角）
  ├─ 贝叶斯推理的概率信念表示（信念热度图）
  └─ 槽位化动作空间（将动作空间编码为结构化槽位，降低非法输出概率）
        │
        ▼
LLM 网关（OpenAI 兼容协议 / JSON 强制输出模式）
        │
        ▼
规则约束下的输出合法性保障机制（逐条校验 → 有限重试 → 回退规则 AI）
        │
        ▼
动作执行 → 对局录制 → 质量分档 → SFT/DPO 数据集 →（计划）QLoRA 微调
        ▲                                              │
        └──────────── 评测回归（L1/L2 两级指标）◄──────┘
```

### 4.2 观测编码层（StateEncoder）

针对 LLM 的三类典型失效模式设计：**信息泄露**（将反派身份等信息错误暴露给正派模型）通过信息边界过滤杜绝；**幻觉与非法动作**通过槽位化动作空间（候选动作枚举 + 范围校验）从输入侧收窄输出空间；**推理信息不足**通过信念热度图将贝叶斯推断的中间结果注入观测，弥补纯文本描述的概率信息损失。

### 4.3 决策推理层（提示策略）

以 3.1 节的原则体系与四段式思维链为骨架构造系统提示词，配合 JSON 强制输出模式约束响应格式；输出经规则校验器逐条校验，非法动作触发有限重试，仍失败则回退规则 AI，保证对局不中断。实测该机制达成动作合法率 100%、回退率 0%。

### 4.4 反馈优化层（数据飞轮与微调计划）

以对局录制器持续积累决策点样本，经质量分档与人机协同标注后形成 SFT/DPO 数据集；**计划**按以下路径完成参数化微调：

1. **基座与工具选型**：Qwen2.5 系列 + LLaMA-Factory，QLoRA（4bit 量化 + 低秩适配）训练；
2. **规模阶梯**：先以 3B 模型在 8GB 显存上训练获得基线（显存富余）；效果不足时升级 7B（峰值显存约 7GB，需梯度检查点与小 batch）；DPO 仅建议在 3B 规模进行（双答案前向显存紧张）且需先扩充成对数据至 1k 以上；
3. **部署形态（计划）**：本地常驻推理服务（OpenAI 兼容端口），权重启动时加载一次、常驻显存；智能体大脑保持无状态（每次决策 = 观测 JSON → 推理 + 动作），每局会话独立维护自身历史，天然支持多房间并发；GPU 批处理（continuous batching）合并多局请求；推理服务不可用时自动降级规则 AI。

### 4.5 评测回归层

每次策略迭代（提示词版本、微调权重版本）均运行自动化基准回归：按难度档各 100 局，统计 L1 三指标与 L2 胜率/命中率，与历史基线对比，防止策略退化。新模型按版本目录管理（models/v1、v2…），旧版保留可回滚。

## 五、拟解决的关键问题与创新点

### 问题一：LLM 在信息不对称博弈中的幻觉与非法动作问题

LLM 的生成式本质使其在结构化决策任务中易输出非法动作或臆造推理依据。**创新点**：提出"领域知识蒸馏提示策略 + 规则约束下的输出合法性保障机制"双层方案——以原则化提示、四段式思维链与槽位化动作空间约束生成过程，以逐条校验、有限重试与回退链兜底生成结果，实现动作合法率 100%。

### 问题二：博弈决策训练数据稀缺与标注成本高昂

策略博弈的高质量决策数据难以获取，人工对局与标注成本极高。**创新点**：提出自举式训练数据生成与迭代优化管线——规则 AI 自对弈（可验证的规模数据）+ LLM 对局（含思维链的高质量数据）+ 自动质量分档 + 人机协同标注框架，以极低人工成本构建可投入微调的数据集。

### 问题三：LLM 推理成本与实时性的矛盾

云端 API 推理按 token 计费，长期成本线性增长；通用大模型决策延迟难以满足对局实时性。**创新点**：提出分级降本路线——先以提示策略在零训练成本下达成可用智能体，再以本地 QLoRA 微调将能力"焊入"小模型权重，实现消费级显卡上的常驻部署与零边际推理成本，形成"提示词先行、微调固化"的完整演进路径。
