# 《幸せの糸》智能体智能水平评价标准与进度展示方案

> 用途：为 LLM 游戏智能体设定分层、可量化、可自动评测的智能水平评价标准，并以此为准绳展示毕业设计的工作进度。
> 数据来源：论文窗口 2.3 表实测值（唯一数据源）；未完成项一律标注"计划"。

---

## 一、设计目标与原则

评价标准需同时满足四个用途：**衡量水平**（当前智能体有多强）、**驱动迭代**（下一步往哪努力）、**展示进度**（答辩与文档中一目了然）、**防止退化**（每次改动可回归比对）。据此确立四条设计原则：

1. **可量化**：所有等级由自动评测的客观指标定义，无主观成分；
2. **可复现**：固定种子局面集，任何权重/提示词版本可重测，结果可比；
3. **双锚定**：门槛采用"绝对阈值 + 相对规则基线"双锚——规则 AI（RuleBrain）三档在同场景下的数值是动态参照系，避免版本间数值漂移导致标准失效；
4. **门禁制**：等级依次递进，上一级达标才开启下一级评测，达标时间即进度里程碑。

## 二、评价指标体系

| 维度 | 指标 | 口径 | 作用层级 |
|---|---|---|---|
| 行为可靠性（底线） | 动作合法率 | 通过引擎校验的动作占比（含重试后） | L1 门禁 |
| | JSON 格式正确率 | 输出可解析为合法动作 JSON 的占比 | L1 门禁 |
| | 回退率 | 重试耗尽后回退规则 AI 的决策占比 | L1 门禁（≤5%） |
| 策略强度（核心） | 分难度胜率 | 正派侧 100 局对局胜局占比（easy/normal/hard 分档） | L2/L3 门禁 |
| | 监视命中率 | 正派每次监视平均命中真实反派数（0~3） | L2/L3 门禁 |
| 推理质量（过程观测） | 思维链四段完整率 | 含完整"看到→推断→比较→决定"的样本占比 | 展示性指标（不进门禁） |
| | 原则遵循率 | 标注分档中 A/B 档占比 | 展示性指标 |
| 工程代价（附加） | 决策延迟 / 单局成本 | 单决策 ms；云端按 token 计费 vs 本地零边际成本 | 展示性指标 |

> 门禁只卡"行为可靠性 + 策略强度"两类硬指标；推理质量与工程代价作为过程观测指标，随进度一并展示但不设关卡，避免门槛过载。

## 三、能力等级标准（L0 ~ L4 门禁制）

```
L0 未达标 ──► L1 基础操作 ──► L2 策略理解 ──► L3 复杂决策 ──► L4 泛化
（可交互）     （会下棋）      （会推理）      （会对抗）      （举一反三）
```

### L0 未达标
定位：能接入对局、可交互，但可靠性或策略未达底线。
门槛：动作合法率 < 100%，或 easy 档胜率 < 50%。

### L1 基础操作（能合法完成对局）
定位：智能体成为"合格玩家"的前提——每一步动作都合法、对局永不卡死。

| 指标 | 门槛 | 当前值 | 状态 |
|---|---|---|---|
| 动作合法率（含重试后） | = 100% | 100% | ✅ 已通过 |
| JSON 格式正确率 | ≥ 99% | 100% | ✅ 已通过 |
| 回退率 | ≤ 5% | 0% | ✅ 已通过 |
| 边界场景走完率 | 100% | 100% | ✅ 已通过 |

### L2 策略理解（掌握规则内推理）
定位：稳定复现"懂规则"的水平——推理链可解释、不犯基础错误。

| 指标 | 门槛 | 当前值 | 状态 |
|---|---|---|---|
| vs easy 档胜率 | ≥ 80% | 80% | ✅ 已通过 |
| vs easy 档命中率 | ≥ 1.70（基线 1.80） | 1.88（超基线） | ✅ 已通过 |
| 基础错误率（监视已死者/已排除者等） | = 0 | 0（合法率 100% 隐含） | ✅ 已通过 |

### L3 复杂决策（多回合规划与对抗）
定位：在最强规则对手（hard 档）面前具备对抗能力——这是"智能体替换规则 AI 上线"的分水岭。

| 指标 | 门槛（双锚定） | 当前值 | 差距 |
|---|---|---|---|
| vs hard 档胜率 | ≥ max(45%, 规则基线×90% ≈ 43%) | 40%（基线 48%） | 差 5~8 个百分点 |
| vs hard 档命中率 | ≥ 1.70 | 待测 | — |
| 残局集（第 4/5 回合截断续打）胜率 | ≥ 规则基线同场景水平 | 待测 | — |
| vs normal 档胜率 | ≥ 55%（基线 62%×90%） | 58% | ✅ 已达 |

> 当前 LLM 智能体 vs hard 胜率 40%、vs normal 58%：normal 子项已达标，hard 子项差约 5~8 个百分点。**L3 是 SFT 微调的主攻目标。**

### L4 泛化（未见局面与规则变体）
定位：能力可迁移——新种子不退化、变体规则不失态、干扰下决策稳定。

| 指标 | 门槛 |
|---|---|
| 新种子性能保持率 | 较 L3 基准下降 ≤ 5% |
| 规则变体（4 反派局等）合法率 | = 100%，命中率不低于规则基线同场景 |
| 干扰鲁棒性 | 与无干扰对照差异 ≤ 5% |

> L4 为"智能体专属难度档"开放门槛，列为后期计划。

## 四、当前进度落点（总览）

| 等级 | 状态 | 达标依据 |
|---|---|---|
| L1 基础操作 | ✅ 已通过 | 合法率 100% / 格式 100% / 回退 0% |
| L2 策略理解 | ✅ 已通过 | easy 胜率 80%、命中率 1.88（基线 1.80） |
| L3 复杂决策 | ⏳ 进行中 | normal 58% 已达标；hard 40%（差 5~8 个百分点） |

| M1 架构落地 | 2026-07 ~ 08（已完成） | Brain 双后端插拔、LLM 网关、校验回退链 | L0 → L1 ✅ |

> 提示词三轮迭代的逐轮数据（easy 50%→80%、hard 30%→40%）本身就是"能力爬升曲线"的最佳素材，答辩展示时与里程碑一一对应。

## 六、评测执行机制

1. **固定评测集**：每难度档 100 个种子局面（对局 ID 可复现），每版本重测，输出 JSON 报告（胜率/命中率/合法率/延迟/成本）；
2. **训练-评测硬隔离**：评测集种子不进任何训练数据与提示样例，防止数据泄漏污染等级判定；
3. **版本化回归**：新权重/新提示词落地前跑全量回归，与上一版本基线对比，任一门禁指标回退即阻断上线；
4. **权重版本目录**：models/v1、v2…旧版保留，等级判定可随时回溯至任意历史版本重测。

## 七、答辩展示建议

- **一张总览表**：L0~L4 等级 × 门槛 × 当前值 × 状态（本方案第四节），直观呈现"已到 L2、冲刺 L3"；
- **一条爬升曲线**：胜率/命中率随里程碑（提示词三轮、SFT 前后）的变化，锚定规则基线画参考线；
- **一组消融对照**（计划）：纯提示 vs +SFT vs +SFT+DPO 三柱对比，展示各技术手段的增量贡献；
- **一条时间线**：M1~M5 里程碑与等级推进对应关系（本方案第五节）。
