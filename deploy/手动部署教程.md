# 《幸福的丝线》手动部署手把手教程

> 全程约 15~30 分钟，无需编程基础，跟着点即可。
> 目标：获得一个 `http://你的服务器IP` 网址，任何设备都能访问并完整游玩（含联机）。

---

## 第 0 步：准备材料

| 材料 | 说明 |
|------|------|
| 一台云服务器 | 推荐腾讯云/阿里云的**轻量应用服务器**，2核2G 或 2核4G，选 **Ubuntu 22.04** 系统（约 ¥50-100/月，新用户常有低价） |
| 部署包 | 本教程同目录的 `happy-threads-deploy.zip`（已打包好） |

---

## 第 1 步：购买服务器

以腾讯云轻量服务器为例（其他平台类似）：

1. 打开腾讯云官网 → 轻量应用服务器
2. 选配置：
   - **地域**：离你最近的（如广州/上海）
   - **镜像**：系统镜像 → **Ubuntu 22.04 LTS**
   - **套餐**：2核2G 起步（内存不足时后端会启动失败，建议 2核4G）
3. 购买后进入控制台 → 记下 **公网 IP**

⚠️ **必须做**：在「防火墙」里放行端口：
- ✅ 80 端口（网页访问，必须开）
- ❌ 3000 / 3306 端口（内部用，**不要开**，安全）

---

## 第 2 步：登录服务器（两种方式任选）

### 方式 A：宝塔面板（推荐新手，全程可视化）
1. 服务器控制台 → 「重置密码」设置 root 密码
2. 浏览器打开宝塔官网 → 一键安装脚本，复制 Ubuntu 脚本
3. 在腾讯云控制台点击「远程登录」（网页终端），粘贴执行
4. 安装完成后会显示 `http://IP:8888/xxxxx` 面板地址和账号密码，浏览器打开
5. 宝塔面板 → 软件商店 → 安装 **Docker 管理器**（无需装 PHP/MySQL 等，容器里都有了）

### 方式 B：SSH 命令行（Windows 用户）
1. Windows 自带终端 PowerShell 或 CMD：
   ```
   ssh root@你的服务器IP
   ```
   输入密码回车即可进入服务器
2. 安装 Docker（复制整行粘贴执行）：
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. 验证：
   ```bash
   docker --version
   ```

---

## 第 3 步：上传部署包

### 方式 A：宝塔面板
1. 面板 → 文件 → 进入 `/root` 或 `/opt`
2. 点击「上传」→ 选择本机 `happy-threads-deploy.zip`
3. 右键 zip → 「解压」→ 得到 `deploy` 文件夹

### 方式 B：命令行（本机 PowerShell）
在你电脑的 PowerShell 里执行（IP 换成你的）：
```powershell
scp "D:\work\gamemake\happy-threads-deploy.zip" root@你的服务器IP:/root/
```
然后回到服务器终端：
```bash
cd /root
apt install -y unzip
unzip happy-threads-deploy.zip
cd deploy
```

---

## 第 4 步：修改密码和密钥（必做）

```bash
cd deploy        # 宝塔面板则先进入 /root/deploy 或 /opt/deploy
nano .env        # 宝塔面板可右键 .env → 编辑
```

把文件改成：
```ini
MYSQL_ROOT_PASSWORD=改成你自己的强密码（如 Xy9#k2pL）
JWT_SECRET=改成任意长随机字符（如 8f3a9b2c7d1e4f5a6b7c8d9e0f1a2b3c）
```

保存：
- `nano` 编辑器：`Ctrl+O` 回车保存 → `Ctrl+X` 退出
- 宝塔：点「保存」

---

## 第 5 步：一键启动

```bash
docker compose up -d --build
```

第一次会下载镜像+构建，**等 2~5 分钟**。看到 `Done` 或回到命令行即成功。

查看是否全部启动成功：
```bash
docker compose ps
```

期望看到三个服务都是 Up：
```
NAME                    STATUS
happy-threads-mysql     Up (healthy)
happy-threads-backend   Up
happy-threads-nginx     Up
```

---

## 第 6 步：访问游戏 🎉

打开浏览器（手机、平板、任何设备都可以）：
```
http://你的服务器IP
```

- 点击「注册」创建账号（两个设备注册两个账号就能联机对战）
- 或直接以游客身份进入玩单机模式

---

## 第 7 步：日常管理

| 想做什么 | 命令（服务器终端） |
|----------|-------------------|
| 看后端日志（出问题时用） | `docker compose logs -f backend` |
| 重启游戏 | `docker compose restart` |
| 停止游戏 | `docker compose down` |
| 更新版本 | 重新上传 zip 覆盖 → `docker compose up -d --build` |

## 常见问题排查

**Q1: 网页打不开？**
- 检查服务器防火墙是否放行 80 端口（第 1 步）
- 检查 `docker compose ps` 三个服务是否都 Up

**Q2: 页面打开但登录/注册报错？**
```bash
docker compose logs -f backend
```
看是否有 MySQL 连接错误 → 检查 `.env` 密码是否和 compose 一致，改完重新 `docker compose up -d`

**Q3: 匹配一直"正在寻找对手"？**
- 确认双方都已注册账号（游客无法匹配）
- 浏览器 F12 → Network → 找 `/socket.io/` 请求，看状态是否 101

**Q4: 想用域名访问？**
- 域名解析 A 记录指向服务器 IP
- 然后 Nginx 配置 `server_name 你的域名`（在 `nginx/conf.d/default.conf`）

**Q5: 想加 HTTPS？**
- 推荐用宝塔面板的 SSL 功能（自动申请免费证书），或参考 `README.md` 的 Caddy 方案
