# 开场视频放置指南

开始页的视频从 `frontend/public/placeholder-videos/` 目录加载。
制作好视频后放入对应文件，刷新页面即可生效（无需改代码）。

## 文件结构

```
frontend/public/placeholder-videos/
├── bg.mp4      背景视频（待点击时全屏循环播放，建议 10~30 秒）
└── intro.mp4   过渡视频（点击后播放一次，播完进入模式选择，建议 3~10 秒）
```

## 说明

- **视频缺失时**：自动回退显示粒子动画背景 + 标题，点击后 3 秒自动进入模式选择，游戏不受影响
- 建议 MP4 格式（H.264 编码，浏览器兼容性最好）
- 视频默认 `muted`（静音）播放，避免浏览器自动播放限制
- 背景视频建议循环友好（首尾衔接）
- 过渡视频播完自动进入「单人模式 / 联机模式」选择界面，也可点击任意处跳过
