# 数据集标注指南 v1（《幸福的丝线》决策样本）

> 版本：v1 ｜ 2026-09-02 ｜ 适用样本来源：`agents/recorder.py` 导出的 selfplay_raw、人类对局录制、出声思考记录
> 依据：`agent-singleplayer-upgrade-plan.md` §2.3 / §2.4

---

## 0. 样本形态

一条样本 = 一个**决策点**（正派选 3 个监视目标，或反派选卡+标记方案）。录制器已自动生成：

- `decision_point`（公开状态 + 信念 + 合法动作空间）——**不可手改**，改则作废（局面失真）；
- `ai_label`（当次决策方 AI 的选择）——可被你的标注**推翻**；
- `ai_annotation`（**AI 标注员草稿**，`annotator=ai_annotator_v1`，2026-09-02 起）——预填的推理草稿 + 事后核对 outcome，**供你审改**：同意则 `human_label` 直接写"同意 AI 标注员"并签名，不同意则在 `human_label` 写你的版本；
- `human_label` / `outcome` / `quality` —— 待标注字段（见 §2）。

## 1. 标注任务（只标这几项）

| 字段 | 说明 |
|---|---|
| `human_label.thought_process` | 四段式思维链（核心劳动，见 §2） |
| `human_label.principles_used` | 用到的原则枚举：`exclude_killed` / `region_constraint` / `overlap_boost` / `count_deduction`(P3) / `release_fishing`(P4) / `cross_round_overlap`(P5) / `nine_grid_priority`(P2) / `replay_check`(P8) / `dilution`(R1) / `card_scheduling`(R2) / `anti_purge`(R6) |
| `human_label.chosen_action` | 若你不同意 AI 选择，给出你的选择（结构同 `ai_label`） |
| `human_label.confidence` | 0~1，你对"chosen_action 是最优解"的信心 |
| `outcome` | 事后回填：命中数 / 本局胜负 / 反事实备注（可选） |
| `quality.grade` | A（可用）/ B（有瑕疵需备注）/ C（作废） |

## 2. 思维链四段式（硬要求）

每条 `thought_process` 必须按"**看到 → 推断 → 比较 → 决定**"写 2~6 句，且**只引用可核实事实**（角色编号、标记位置与形状、回合数、卡行动次数）。禁止只写"感觉某人是反派"。反例与正例：

> ❌ "302 很可疑，就监视他。"
> ✅ "第 2 回合 404 被十字标记，凶手必在 {401,402,405,604,504,304,204} 中；402 同时落进第 1 回合 502 九宫格的范围 → 402 同时满足两刀约束，权重最高；比较 304 与 504：304 上回合已被监视过无新信息 → 最终选 {402, 401, 504}。"

## 3. 最优动作判定三标准（优先级：a > b > c）

- **a) 规则共识（一票否决）**：违背排除法的动作直接判错——监视已死亡/已标记/恒死者、反派越范围标记、不满足满员行动、标记同伙、重复监视。出现即 B/C 级。
- **b) 长期模拟**：以该动作为节点，双方 hard 档模拟 100 局比较胜率/命中率（工具：`benchmark.py` 思路 + 固定种子）。
- **c) 人类共识**：多人标注取多数。

## 4. 等价多解

当多个候选动作在 b) 标准下无显著差异（模拟胜率差 < 2%）时，标记为"等价多解"：`chosen_action` 之外的等价解写入 `quality.issues`（如 `"等价解: [601,604,505]"`）。训练时作为可接受集合而非唯一答案。

## 5. 一致性与质量控制

| 机制 | 标准 |
|---|---|
| 金标准集 | 20 条规则共识样本（答案已知）作为**校准集**，标注前先做，误差 >1 条即回炉读指南 |
| 双标注 | 每批 10% 双人标注（你 + AI 标注员），动作不一致以金标准 + 模拟裁决 |
| 一致性指标 | 动作一致率 ≥ 90%；思维链要点重合率 ≥ 80%；低于阈值整批复检 |
| 抽检 | 每周随机抽 10% 复检；grade B/C 强制二审 |
| 版本管理 | 样本带 schema 版本 + 指南版本；游戏规则变更时冻结旧集、开新集（当前规则基线：2026-09-02，含范围内/满员/禁同伙硬规则与 403 复活变体） |

## 6. 优先级建议

1. 先标你自己的**出声思考记录**（S1 级，价值最高）：30~50 条即够启动 few-shot 智能体；
2. 再批改 **selfplay_raw**（S3 级）：挑"有想法"的决策点（残局、多标记重叠、放钓实验局），不必逐条标；
3. 线上对局（S5）随量回灌，长尾局面优先。

## 7. 口语标注输入格式（游戏序号+回合，2026-09-04 起）

日常补充标注用口语即可，两种引用方式任选：

**A. 自对弈样本（docx v2）**：`样本 051`（或 `g-0029-r45658`）即可定位，回合在样本标题里。

**B. 真人双人对局（dataset/ 目录）**：`第X局第Y回合，我是正派/反派` —— 第X局 = `backend-python/dataset/` 下按文件名时间排序的 match 记录；Y = 该局 steps 里的 round。

内容要求：按"看到→推断→比较→决定"说清怎么打的 + 同意/不同意 + 信心即可，几何与格式由 AI 核验后合并。

合并后写入：`human_label`（你的推理链）+ `outcome`（真实命中/胜负）+ `quality`（评级）。已合并的样本不会再重复要标注。
